Self-hosted fonts for Dot.Auction. Nothing is loaded from a CDN at runtime.

chivo-mono-var-latin.woff2   Chivo Mono (variable: weight 100-900, Latin subset)
                             Copyright 2018 The Chivo Project Authors (https://github.com/Omnibus-Type/Chivo)
                             SIL Open Font License 1.1: LICENSE-ChivoMono-OFL.txt
                             Used for exactly one job: data readouts where equal-width digits matter (the sale-room clock, lot numbers,
                             payment references). It is not a text face.

Roboto, the face of every heading, paragraph, button, form, table, menu and price, is not in this folder: it is shared by all Dot platforms and ships
inside the dot-ui copy (public/dot-ui/fonts/roboto/, with its OFL.txt; public/dot-ui/css/dot-roboto.css declares it).
Archivo, the face used before R-52, was removed from the app (file, licence, @font-face and preload).
