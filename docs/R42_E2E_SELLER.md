## Seen, not changed

* The dev-only `/dev/login` route, used on a browser that is already signed in as someone else, ends in a logged-out page (`AuthenticateSession` still holds the first person's password hash). The harness signs out first. The real InfoDot hand-off over another person's session was run and works (S5).
* `X-Powered-By: PHP/8.5.9` comes from the dev server; set `expose_php=0` on the host. The CSP is report-only and allows `unsafe-eval` (the documented Livewire and Alpine constraint). HSTS is correctly absent on http.
* Validation wording is Laravel's ("The title field is required.", "The bid increment field is required."): plain, but not the product's voice. Left, as the brief gives no copy.
* Filtered lists share their page title (`My lots`); see the owner list.
* The seller's sale page does not show the buyer's name at all (an earlier owner question); after an account is erased the lot's bid history reads "Former member".

## Not verified

* **Real payment.** No spec presses Pay now and no Paystack call was made; the gateway error and success paths are untested here (the sale pages around them are covered).
* **Reverb / real-time.** Run with `AUCTION_REALTIME_ENABLED=false` (polling), as production does. Nothing here exercises websockets.
* **E-mail delivery.** Mail is the `log` driver: the team invitation link was read from the log and used, but no SMTP, no Dot.Notify event (reserve notice mail stays off by decision).
* **One browser.** Chrome only (desktop and emulated phone). No Safari, Firefox, real iPhone or Android keyboard, real screen reader, or real touch hardware; "coarse pointer" is emulated.
* **`php -S`, SQLite, one worker.** Concurrency and PostgreSQL are covered by the PHPUnit runs, not by the browser specs. The production web server, `route:cache`/`config:cache` and the host's headers were not run (`tests/Support/signed-in-smoke.sh` does that separately).
* **Host pinning** was tested on a second `php -S` server in production mode, not behind the real proxy; `x-forwarded-*` handling is untested.
* **The 30-day maximum duration, the 4 MB boundary exactly, and a 6th-photo race between two tabs** were not run (the server rule is covered by PHPUnit).
* **2FA for InfoDot-only people** (see owner question 2) and the "Forgot your password?" flow for them were not run.
* **Dark theme** was driven on the create form, sale page, profile, teams and public pages with axe; the rest of the sweep ran in the light scheme.
* **`auction:seed-categories`** does not exist on this branch (feat/r42-sp); skipped.
